개인정보 처리 안내

DOKDO FC · 최종 변경: 2026년 11월 12일

이 사이트는 EA 또는 EA의 라이선스 제공자가 보증하거나 제휴하는 서비스가 아닙니다. DOKDO FC의 비공식 팀 기록 열람 페이지입니다.

1. 운영 주체와 문의

운영 주체: DOKDO FC 커뮤니티 (공개 소스 관리 계정: insungmeta). 운영 관련 문의: GitHub 공개 이슈 또는 소속 클럽 운영진을 통한 별도 연락. GitHub 이슈는 누구나 볼 수 있으므로 이메일·전화번호·실명·신분증 등 민감하거나 식별 가능한 내용을 게시하지 마세요. 앱 출시 전 별도의 개인정보 담당 연락처 확인이 필요합니다.

2. 표시하는 데이터

게임에서 사용한 닉네임, 클럽 소속 및 포지션 표기, 경기 결과, 출전, 득점·도움·평점·카드 등 경기 통계가 공개 화면에 표시됩니다. 닉네임도 상황에 따라 개인을 식별할 수 있으므로 개인정보로 취급해야 할 수 있습니다. 타인이나 과거 멤버의 기록도 포함될 수 있습니다.

3. 수집 경로와 목적

현재 운영 코드는 제3자가 개발한 비공식 FC 클럽 기록 접근 라이브러리로 경기 정보를 받아 저장합니다. 이 방식은 EA가 승인한 공식 API를 사용한다고 보장할 수 없으며, 관련 이용 권한은 별도로 검토해야 합니다. 통계 표시는 클럽 활동 확인·경기력 분석을 위한 것이며 광고 또는 계정 판매 목적으로 사용하지 않습니다.

4. 계정·로그·제3자 서비스

  • 홈페이지 통계를 보기 위해 EA 계정 비밀번호나 전화번호를 제출할 필요가 없습니다.
  • 웹페이지는 GitHub Pages에서 제공됩니다. 호스팅 사업자가 접속 IP·요청 기록 등 서버 운영 정보를 처리할 수 있습니다.
  • 게시판의 글쓰기·댓글은 GitHub로 이동해 GitHub 계정으로 작성되며, 계정·게시물 정보는 GitHub 정책에 따릅니다.
  • 기존 전체 기록 화면은 Google Fonts의 웹 글꼴을 불러올 수 있어 해당 서비스에 브라우저 요청이 발생할 수 있습니다.
  • 알림 연동 코드가 있으나 현재 알림 설정은 비활성화되어 있습니다. 활성화할 경우 관련 안내를 갱신합니다.
  • 일부 환경에서 선택한 인터페이스 설정 등이 브라우저에 보관될 수 있습니다. 데이터의 다른 사이트 전송을 위한 자체 광고 추적 코드는 현재 설정하지 않았습니다.

5. 보관 기간·삭제 요청

공개 경기 아카이브는 현재 명시적 자동 삭제 기한 없이 누적 보관됩니다. 본인의 닉네임·기록에 대해 표시 제외나 삭제를 요청할 수 있으며, 타인 기록에 관한 요청은 권리 확인이 필요할 수 있습니다. 삭제 시 공개 페이지·저장소·과거 커밋·캐시·외부 복제본의 범위를 각각 확인해야 하므로 모든 복제본의 즉시 삭제를 보장할 수 없습니다.

6. 보안과 문의 시 주의

사이트 접속은 HTTPS를 사용합니다. 그러나 HTTPS만으로 데이터 수집 권한, 게시물의 진위, 제3자 서비스의 보안을 보장하지는 않습니다. 민감한 개인정보를 공개 게시판에 올리지 마세요.

7. 정책 변경

데이터 수집 방식, 외부 알림 서비스, 앱 배포·기능이 변경되면 이 안내도 함께 검토·수정합니다. 이 페이지는 법률상 의무 이행을 보증하는 확인서가 아닙니다.

Privacy Notice

DOKDO FC · Updated 12 November 2026

This independent fan project is not endorsed by or affiliated with EA or its licensors.

1. Operator and contact

Operator: DOKDO FC community (public code maintainer: insungmeta). Contact: public GitHub issues or your club administrators. GitHub issues are public: never publish an email address, real name, phone number, ID, or other sensitive details. A separate privacy contact must be confirmed before app publication.

2. Data displayed

Public club records may include gamer tags, listed positions, appearances, match scores, goals, assists, ratings and disciplinary events. Gamer tags may be personal information if they identify someone. Historical and former member records may appear.

3. Sources and purpose

The current code uses a community-built, unofficial FC clubs statistics reader. Authorization from EA for this data collection has not been established. Stats are displayed for community match records and tactical analysis, not sold as account data.

4. Accounts and external services

  • No EA account password, phone number or sign-in is required to view stats.
  • GitHub Pages hosts the site and may process server request logs and network addresses.
  • Writing in the club board occurs on GitHub and is governed by GitHub's own terms and privacy policy.
  • The archived full-records page may request web fonts from Google Fonts.
  • Optional notification integration code exists, but notifications are currently disabled.
  • Browser-local preferences may be stored. No custom advertising tracking is currently configured.

5. Retention and removal requests

Archived match records currently have no automatic expiry. Players may request that identifiable records be hidden or removed. Requests about another person may require evidence of authority. Current pages, repository history, caches and outside copies may require different removal steps; immediate deletion everywhere cannot be promised.

6. Security

HTTPS protects transport, but does not prove permission to reuse data or eliminate all risks. Do not share sensitive personal information in public issues.

7. Changes

This notice will be reviewed if data sources, notifications or mobile app behavior change. It does not certify regulatory compliance.
