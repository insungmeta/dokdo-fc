# DOKDO FC 카카오 오픈채팅 자동 알림봇 (0원 실험 버전)

이 디렉터리는 Android **메신저봇R API2**용 스크립트입니다. 별도 서버 요금은 없으며 DOKDO FC 홈페이지의 공개 JSON을 5분마다 확인합니다.

- 스크립트: [DFC-OpenChat-API2.js](./DFC-OpenChat-API2.js)
- 홈페이지: https://insungmeta.github.io/dokdo-fc/
- 원본 경기 데이터: https://insungmeta.github.io/dokdo-fc/data/dashboard.json

## 꼭 알아야 할 것
- **실제 카카오 오픈채팅방 자동 발송은 아직 현장 검증되지 않았습니다.** 앱/OS/알림 세션에 따라 작동하지 않을 수 있습니다.
- 공식 카카오톡 API가 아니라 **비공식 알림 기반 자동응답** 방식입니다. 개인정보·알림 접근 권한과 카카오 정책/계정 제재 가능성을 이해하고 사용하세요.
- **경기 시작 실시간 알림은 구현할 수 없습니다.** 현재 EA 조회 데이터는 주로 종료 후 결과를 공개합니다. 이 봇은 경기 종료 후의 *새 기록 발견 알림*입니다.
- GitHub Actions 기록 업데이트 기본 주기가 약 30분이고 스케줄링이 지연될 수 있습니다. 봇이 5분마다 확인해도 메시지가 실시간으로 오지는 않습니다.
- 공기계/태블릿은 켜져 있어야 하고 Wi-Fi와 카카오톡 알림·봇 알림 접근 권한이 유지되어야 합니다. 카톡방 알림을 끄면 수신 세션이 사라질 수 있습니다.
- 사용 기기에서 카카오톡에 로그인할 때 기존 기기의 카톡 세션에 영향이 있을 수 있으므로 먼저 기기별 로그인 정책을 확인하세요.

## 5G 안드로이드 태블릿 권장 구성 (PC 필요 없음)
- **전용 카카오 계정**으로 DOKDO FC 오픈채팅방에 입장합니다. 기존 개인 계정은 봇과 분리합니다.
- 설치: [메신저봇R 공식 다운로드 센터](https://download.msgbot.app/)에서 최신 안정 버전 사용. 구형 Play 스토어 버전은 피하세요.
- **설정 → 알림 → 앱 알림 → 카카오톡 ON**, 해당 오픈채팅방의 메시지 알림 ON.
- **설정 → 앱 → 메신저봇R → 배터리 → 제한 없음**(메뉴명은 삼성 One UI 버전에 따라 다름). 메신저봇R의 알림 접근 권한을 허용하세요.
- 태블릿은 5G/와이파이 연결을 유지합니다. **별도 서버나 PC를 켜둘 필요 없습니다.**
- 앱이 읽는 카카오톡 알림에는 개인정보가 포함될 수 있으므로 전용 계정으로 운영하세요.

## 최초 실기기 테스트
1. 태블릿에서 카카오톡 전용 계정으로 방에 입장하고, 카톡/메신저봇R의 알림과 배터리 설정을 완료합니다.
2. 메신저봇R에서 **API2** JavaScript 봇을 만들고 [스크립트](./DFC-OpenChat-API2.js)를 붙여넣습니다.
3. 맨 위 `REQUIRED_ROOM`을 실제 오픈채팅방 제목과 동일하게 설정하고 저장·컴파일 후 활성화합니다.
4. 태블릿 카카오톡을 **백그라운드**에 두고, 다른 카카오 계정(방장 계정)으로 오픈채팅방에 `!DFC테스트` 를 보냅니다.
5. 봇이 **테스트 응답 성공**이라고 답하면 세션이 확보된 것입니다. 답이 없으면 알림 접근 허용/방 제목/카톡 방 알림을 확인합니다.
6. 이어서 다른 카카오 계정(운영자 계정)으로 `!DFC등록` 을 보내세요. **첫 등록자가 관리자**로 고정됩니다. 임의의 팀원이 먼저 등록하지 않도록 바로 실행하세요.
7. `!DFC상태` 에서 초기화 완료를 확인한 뒤, 같은 운영자 계정으로 `!DFC켜기` 를 보내세요.
8. 테스트는 먼저 팀원에게 안내하거나 테스트 방에서 검증하고, 실제 경기 종료 후 새 기록이 게시될 때 자동 메시지를 확인하세요. 5분마다 체크하지만 데이터 갱신은 약 30분 간격입니다.

### 등록과 운영 권한
- 최초 `!DFC등록`을 보낸 카카오 계정이 관리자입니다. 이후 `!DFC켜기`, `!DFC끄기`, 재등록은 **같은 발신자**만 허용됩니다.
- 계정 구분은 알림에 포함된 발신자 해시를 우선 사용하며, 해시가 없는 환경에서는 닉네임만으로 비교하는 제한이 있습니다. 관리자 인증용 보안 시스템은 아닙니다.
- 명령 `!DFC테스트`, `!DFC상태`, `!전적`, `!최근경기`, `!득점왕`, `!도움왕`, `!골키퍼`는 방 안에서 사용할 수 있습니다.
- 등록자의 카카오 닉네임이나 오픈채팅방 이름이 바뀌면 동작에 영향을 줄 수 있습니다.

## 설정 (방장 직접 1회)
1. 위 공식 다운로드 센터에서 **메신저봇R 최신 안정 버전**을 설치하고, 태블릿의 별도 카카오 계정으로 로그인합니다.
2. 메신저봇R에서 새로운 JavaScript **API2** 프로젝트를 만들고 `DFC-OpenChat-API2.js`의 코드를 붙여 넣은 후 저장·컴파일·실행합니다.
3. 코드 위쪽 `REQUIRED_ROOM = "DOKDO FC"`를 **실제 오픈채팅방 제목과 똑같이** 설정합니다.
4. 해당 기기의 카카오톡에서 DOKDO FC 오픈채팅방을 **입장한 상태로 계속 열어두지 말고**, 채팅방의 새 메시지 *알림*이 실제로 기기에 오는지 확인합니다.
5. 먼저 다른 계정으로 `!DFC테스트`를 보내 알림 세션을 확인한 후, 운영자 계정으로 `!DFC등록` 메시지를 보냅니다. 첫 수집에서 기존 경기 ID를 기억하여 과거 기록을 도배하지 않습니다.
6. 봇에서 등록 완료 메시지가 오고 초기화된 뒤 `!DFC켜기`를 입력합니다. 이후 새로운 *종료 경기 기록*이 게시되면 자동 메시지를 시도합니다.
7. `!DFC상태`로 상태를 확인합니다. 중단은 관리자 계정의 `!DFC끄기`입니다.

## 채팅방에서 사용 가능한 명령
- `!전적`: 전체 승무패, 득실점
- `!최근경기`: 최근 리그 경기 상세 요약
- `!득점왕`: 시즌 득점 상위 5명
- `!도움왕`: 시즌 도움 상위 5명
- `!골키퍼`: 실제 클럽 명단 GK 시즌 클린시트·평점
- `!DFC테스트`: 앱이 실제로 카톡 메시지에 답장할 수 있는지 점검\n- `!DFC상태`: 데이터 갱신 시각·오류·저장된 경기 확인\n- `!DFC등록`, `!DFC켜기`, `!DFC끄기`: 관리자 명령

## 구현 범위 및 위험
- 동일 경기 `matchType:matchId`로 중복 발송 방지, 초기 설치 시 기존 경기 전체 발송 방지, 일정 시간 중단 후 최대 3경기만 알림
- 메시지 전송은 메신저봇 `Bot.send(room, text, "com.kakao.talk")`의 알림 회신 세션을 사용합니다. 세션이 없으면 발송이 실패합니다.
- 카카오톡 공식 API를 사용하는 방식이 아닙니다. 자동화가 카카오 약관과 호환되는지 사용 전에 확인해야 합니다.
- **개인정보 주의:** 알림 접근 권한은 팀 채팅뿐 아니라 다른 기기 알림 내용에도 접근할 수 있습니다. 공기계 사용을 권장합니다.
- 사용자님의 휴대폰에 직접 설치하거나 카톡방에 접속할 수는 없습니다. 실제 기기에서 실행·권한 허용이 필요합니다.

공식 메신저봇R API2 참고: https://kbotdocs.dev/reference/api2/Object/Bot/send 및 https://kbotdocs.dev/reference/api2/Object/Http/request%28Object%2CFunction%29
